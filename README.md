# AltNotes

A lightweight notes addon for tracking your alts.

## What it does

AltNotes lets you store simple notes for each of your characters, so you can keep track of things like:

* What each alt is working on
* Weekly or daily tasks
* Professions, goals, or reminders

## Why use it

If you play multiple characters, it’s easy to forget what each one was doing. AltNotes gives you a quick, in-game way to keep everything organized in one place.

## Features

* Per-character notes
* Simple and clean interface
* Lightweight with no unnecessary extras

## Usage

Open the addon in-game and write notes for your current character. Each alt has its own separate notes.
